# Rawad_Project_CodeCenter_OmarAlsultan
# منصة رواد — Rwad Platform

موقع تسويقي لمنصة **رواد** متخصصة في تقديم الحلول الرقمية من تصميم وتسويق وتطوير مواقع.

---

## 🗂️ هيكل المشروع

```
rwad-platform/
├── index.html          # الصفحة الرئيسية
├── services.html       # صفحة الخدمات
├── about.html          # صفحة من نحن
├── contact.html        # صفحة تواصل معنا
├── product_0.html      # التسويق الإلكتروني
├── product_1.html      # إدارة صفحات سوشيال ميديا
├── product_2.html      # إدارة الحملات الترويجية
├── product_3.html      # إنشاء المواقع الإلكترونية
├── product_4.html      # تحسين محركات البحث SEO
├── css/
│   └── style.css       # ملف التنسيق الرئيسي
├── js/
│   └── script.js       # قائمة الموبايل
└── images/             # مجلد الصور
```

---

## 📄 الصفحات

| الصفحة | الوصف |
|--------|-------|
| `index.html` | الصفحة الرئيسية — Hero, خدمات, لماذا نحن, آراء العملاء, النشرة البريدية |
| `services.html` | عرض جميع الخدمات مع services-box |
| `about.html` | معلومات عن المنصة والفريق |
| `contact.html` | نموذج تواصل مع خريطة ومعلومات الاتصال |
| `product_0.html` | تفاصيل خدمة التسويق الإلكتروني |
| `product_1.html` | تفاصيل إدارة السوشيال ميديا |
| `product_2.html` | تفاصيل إدارة الحملات الترويجية |
| `product_3.html` | تفاصيل إنشاء المواقع الإلكترونية |
| `product_4.html` | تفاصيل تحسين محركات البحث SEO |
